## Linux command :

- `r` — Read
- `w` — Write
- `x` — Execute
  
___

Usage of 'pwd' :

Use `pwd` to view the print working directoy 

```bash
pwd
```
---

It can be divided into:

```text
- | rwx | r-x | r--
  |     |     |
  |     |     └── Others
  |     └──────── Group
  └────────────── User
```
